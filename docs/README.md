# Web Scraper Agent Documentation

Local development:

```bash
npm install
npm run start
```

Build for production:

```bash
npm run build
npm run serve
```

Deploy to GHE Pages (from this directory, on `main`):

```bash
GIT_USER=chris-rudnicky USE_SSH=true npm run deploy
```

Published site: `https://ghe.megaleo.com/pages/chris-rudnicky/scraper/`
